# National Housing Price Prediction

An end-to-end machine learning project that predicts U.S. home values from national
housing survey data, with a Streamlit app for interactive predictions.

## Overview

- **Dataset:** ~35,000 household records, 22 raw features (numeric + categorical)
- **Target:** `VALUE` — self-reported home value in $
- **Models trained:** Linear Regression, SVR (RBF kernel), XGBoost
- **Deployment:** Streamlit web app for live predictions

## Pipeline

1. **Data cleaning** — drop duplicates, engineer `House_Age` from `DATE` and `BUILT`
2. **Train/test split** — 80/20, all preprocessing fit on the training set only
3. **Missing values** — numeric columns filled with the training median (plus a `_missing`
   flag column); categorical columns filled with the training mode
4. **Encoding** — one-hot encoding of categorical features (`OneHotEncoder`, unseen
   categories ignored at inference time)
5. **Scaling** — `RobustScaler` applied only for the SVR model
6. **Modeling** — all models predict `log1p(VALUE)`; predictions are converted back with
   `expm1()` for dollar-scale comparisons
7. **Evaluation** — MAE, RMSE, and R² (log scale), plus MAE in dollars

## Running the Notebooks

```bash
pip install -r requirements.txt
jupyter notebook notebooks/MLfinale4_updated.ipynb
```

Running `MLfinal.ipynb` end to end regenerates `housing_models.pkl`, which the
Streamlit app depends on.

## Running the App

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the local URL Streamlit prints (usually `http://localhost:8501`). Fill in the
property details in the sidebar, choose a single model or "Compare all 3 models," and
click **Predict** to see the estimated home value and test-set performance metrics.
